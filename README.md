# Vigil Studio

موقع **Vigil** ودليل هويته.

Vigil استوديو إنتاج وتصميم وتراخيص وذكاء اصطناعي: مونتاج وريلز، هوية بصرية، تجهيز ملفات التراخيص، مواقع، ومساعد عملاء ذكي.

## الصفحات
| الملف | وش فيه |
|---|---|
| `index.html` | الموقع بالعربي |
| `en.html` | الموقع بالإنجليزي |
| `brand.html` | دليل الهوية: الشعار، الألوان، الخطوط، الأيقونات، العناصر، والنبرة |
| `assets/` | ملفات الشعار (SVG و PNG) وصورة الحسابات |

## الهوية باختصار
- **الشعار:** حرف V على شكل دائرة إلكترونية ونقطة ذهبية، والاسم بخط Grenze Gotisch.
- **الألوان:** Night `#0E0620`، Deep `#160A30`، Line `#3B1F6E`، Ink `#F6E9FF`، Pink `#FF3EA5`، Cyan `#2DE2E6`، Sun `#FFD23F`، Violet `#7B2FF7`.
- **الخطوط:** Noto Kufi Arabic للعناوين والنصوص، Press Start 2P و VT323 للتفاصيل الإنجليزية والأرقام.
- **الأسلوب:** بكسل آرت على ليل سينثويف، إطارات حادة وهالات نيون ناعمة.
